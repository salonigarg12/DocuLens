# DocuLens

An AI-powered document intelligence platform that enables users to upload PDF documents, generate concise summaries, and interact with them through natural language conversations. DocuLens combines Retrieval-Augmented Generation (RAG), semantic search, and Google's Gemini API to deliver context-aware responses grounded in the uploaded document instead of relying solely on the language model.

---

# Overview

DocuLens is designed to simplify information retrieval from lengthy PDF documents. Instead of manually searching through pages, users can upload a document and ask questions in plain English. The application retrieves the most relevant document sections using semantic similarity search and provides accurate, context-aware answers generated by Gemini.

The project also supports user authentication, persistent chat history, and document management, making it suitable for handling multiple user sessions securely.

# Installation

## Clone the Repository


# How It Works

1. A user logs into the application.
2. A PDF document is uploaded.
3. The document is parsed using **pdfplumber**.
4. The extracted text is divided into overlapping chunks.
5. Each chunk is converted into vector embeddings using Sentence Transformers.
6. Embeddings are indexed using FAISS.
7. When a question is asked, the application retrieves the most relevant chunks through semantic similarity search.
8. The retrieved context and user query are sent to Gemini.
9. Gemini generates a context-aware response grounded in the retrieved document content.
10. The conversation is stored for future reference.
